Stats is a light system monitor that sits in one slim bar: CPU, memory, storage, GPU, temperature and network. When something runs high it tells you which program is to blame and what to do about it.

Install in one command

Pick your system (we guessed it for you), copy the line, paste it in a terminal. That's it.

  1. Open a terminal and run:
    curl -fsSL https://matolojr.github.io/stats/install.sh | bash
  2. Log out and back in once. GNOME on Wayland only loads new extensions at login.
  3. Stats appears in the top bar. Click it for the dashboard.

GNOME Shell 46 to 50 (Ubuntu 24.04+, Fedora 40+, Arch, Debian 13). No root.

What it does

  • A living line

    On Windows, a small line at the top of the screen moves with your machine's activity, like a voice meter, and turns amber or red when something runs high. Click it to drop down every reading; on Linux they sit in the top bar.

  • A dashboard on click

    Live tiles with history graphs, every drive and sensor, and the programs using your memory. Fold the sections you don't watch; folded sections stop refreshing, so they cost nothing.

  • Names the culprit

    When memory or CPU stays high, Stats adds up every process of each program (Chrome ×23 = 4.1 GB) and tells you which one to close.

  • Stops crashes before they happen

    On Windows it watches committed memory against the real limit, checks your page file and offers one-click fixes for WSL, Docker and build folders.

  • Light by design

    No web view, no background service, no telemetry. Sleeping GPUs are never woken up, and polling pauses while the screen is locked.

  • Nothing without a yes

    Stats never closes a program or deletes a file without your click, and never touches parts of the operating system.

Where the numbers come from

No admin rights, no guessing: Stats shows what the operating system reports, and n/a when it doesn't. The documentation goes deeper.

Linux

  • CPU busy share of /proc/stat between polls
  • Memory MemTotal minus MemAvailable
  • Storage per mount point; speed from /proc/diskstats
  • GPU sysfs, nvidia-smi or intel_gpu_top when installed
  • Temperature hwmon (coretemp, k10temp, NVMe, amdgpu)
  • Refresh the nominal mode rate from Mutter

Windows

  • CPU GetSystemTimes
  • RAM and commit GlobalMemoryStatusEx, GetPerformanceInfo
  • Disk, network, GPU performance counters, by English name so any language works
  • GPU busy the busiest engine, as Task Manager does
  • Temperature the ACPI thermal zone, when the laptop exposes one
  • Per program private bytes, the ones that count against the limit

Questions

Why do I have to log out on Linux?

GNOME Shell on Wayland only scans for new extensions when you log in. On X11, press Alt+F2, type r and Enter instead. Later updates need the same.

Windows warns that the app is from an unknown publisher.

The one-line installer doesn't trigger that warning. A stats.exe downloaded in a browser can, because it is not code-signed yet. Choose More info › Run anyway, or check it against SHA256SUMS first.

Where are the settings?

Linux: gnome-extensions prefs stats@local, or right-click the indicator. Windows: right-click the bar › Settings, which opens %APPDATA%\Stats\config.ini. It reloads within two seconds of saving.

How do I update?

Run the same install command again. It replaces the old version in place and keeps your settings.

Does it send anything anywhere?

No. Stats reads local counters only. The installers contact GitHub to download the release, and nothing else.
